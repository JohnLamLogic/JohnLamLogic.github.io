03 // research

Research

ARIS — Authenticated Randomness Infrastructure Service

Senior Design · University of Miami NanoMagnetoElectronics Lab · Ongoing

ARIS is a hardware-based True Random Number Generator (TRNG) that derives entropy from Magneto-Optical Kerr Effect (MOKE) hysteresis measurements of magnetic thin-film samples. The system integrates a Stanford Research SR865A dual-phase lock-in amplifier with FPGA processing to produce cryptographically auditable random bitstreams.

  • Designed and automated a MOKE measurement system using LabVIEW, SR865A lock-in amplifier at 255 Hz chopper reference, and SMA fiber-optic alignment — improving sample throughput ~6× over prior manual workflow
  • Debugged AC/DC overload conditions in the lock-in amplifier chain caused by stray reflections at fiber-sample interface
  • Architected FPGA pipeline to sample lock-in output, apply NIST SP 800-22 statistical validation, and stream entropy to host
  • Built cryptographic audit trail to verify randomness source provenance for downstream applications
  • Validated against NIST test suite: frequency, block frequency, runs, longest run, spectral DFT, and serial tests

Benchmark_AI — Generative AI Evaluation for Hardware Engineering

Ongoing Collaborative Research · 2025–Present

A structured 4-stage benchmarking study evaluating Claude, ChatGPT, and Gemini on hardware engineering tasks of escalating complexity — from basic RTL generation to multi-module FPGA system design. Evaluation is manual, assessing correctness, code structure, and integration quality.

  • 3 platforms evaluated: Anthropic Claude, OpenAI ChatGPT, Google Gemini
  • 4-stage study structure with tasks escalating from logic gate instantiation to pipelined datapath generation
  • Manual evaluation rubric covering synthesizability, timing correctness, and testbench compatibility
  • Ongoing — results and methodology documented in GitHub repo
